## Features

- Service and professional selection
- Interactive date and time picker
- Simulated booking confirmation
- Responsive desktop and mobile navigation
- Distinctive editorial barbershop design

## Architecture

The project follows **Feature-Driven Architecture**:

```text
src/
├── app/                 # Application composition and global styles
├── features/
│   ├── booking/         # Booking state, data and confirmation flow
│   ├── services/        # Service selection
│   └── team/            # Professional selection
└── shared/              # Reusable site components
```

## Run locally

```bash
npm install
npm run dev
```

All people, services and appointments are fictional demo content.
